# 02 — Database Design (MySQL 8, utf8mb4_unicode_ci)

## Global rules

- **Money = unsigned BIGINT in poisha** (৳1 = 100). Never float. Format via `App\Support\Money`.
- **Weight = unsigned INT in grams.**
- **Snapshots:** orders copy product name, unit label, price, estimated cost, category,
  area name and address. Editing a product/area never changes old orders or reports.
- Status columns: PHP backed enums stored as `string(30)`.
- Soft deletes on `categories`, `products`. Never hard-delete anything an order references.
- Every FK indexed.

## ER overview

```
categories (self parent_id, unlimited depth)
   └─< products ─< product_images
areas
customers ─< customer_addresses >─ areas
carts ─< cart_items >─ products            (guest token or customer)
customers ─< orders ─< order_items >─ products
                └─< order_events           (audit trail)
settings
daily_sales_summaries, daily_product_sales  (derived, rebuildable)
users (admins)
```

## Catalog

### categories
| column | type | notes |
|---|---|---|
| id | PK | |
| parent_id | FK self, null | null = top level |
| name | string(100) | Bangla |
| slug | string(120) UNIQUE | English; shared namespace with products |
| image | string null | tile image |
| icon | string null | sidebar icon |
| depth | tinyint | 0 = top |
| path | string(255) | materialized path `/1/5/23/` → descendants via `LIKE '/1/5/%'` |
| is_leaf | bool | maintained by model events |
| is_active | bool | |
| show_on_home | bool | "জনপ্রিয় ক্যাটাগরি" grid |
| home_sort_order | smallint | |
| timestamps, deleted_at | | |

Rules: **products may only belong to a leaf category**; a category that has products
cannot get children (validation). Whole tree (~hundreds of rows) is cached as one
structure by `CategoryTree` and busted on any category save/delete.

Indexes: `(parent_id, name)`, `(path)`, `(show_on_home, home_sort_order)`.

### product_images
`id, product_id FK, path, sort_order, timestamps` — gallery for detail modal; WebP thumb/medium generated by queued job.

## Customers & areas

### areas
`id, name (Bangla), is_active, timestamps` — listed by name A→Z. "অন্যান্য" is **not** a row; the UI always appends it last.

### customers
`id, name, phone UNIQUE (normalized 01XXXXXXXXX), password, is_blocked, orders_count, delivered_count, cancelled_count, last_order_at, remember_token, timestamps`

### customer_addresses
| column | notes |
|---|---|
| id, customer_id FK | |
| recipient_name, phone | default from customer, editable |
| area_id | FK null — **null means "অন্যান্য"** |
| area_other | string(100) null — required when area_id is null |
| address_line | string(500) — house/road/landmark |
| is_default | bool |

## Bag (cart)

### carts
`id, token char(36) UNIQUE null (guest cookie), customer_id FK UNIQUE null, timestamps`
### cart_items
`id, cart_id FK, product_id FK, quantity smallint, timestamps, UNIQUE(cart_id, product_id)`

Bag never stores prices; prices are read live. Guest bag merges into customer bag on login.
Old guest carts pruned by scheduler (30 days).

### order_items

| id, order_id FK | | |

### order_events (audit trail)
`id, order_id FK, order_item_id FK null, type string(40), from json null, to json null, note, user_id null (admin), created_at`
Types: `placed, status_changed, delivery_charge_changed, item_unavailable, item_weight_set, item_quantity_changed, item_cost_set, note_added`.
